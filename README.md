# QuickBridge — Minecraft 1.21.11

**QuickBridge** — client-side Forge-мод с движком автоматизированного бриджинга. Он управляет движением игрока и ставит блоки, ориентируясь на реальное состояние мира, а не только на фиксированные AHK-таймеры.

> Важно: автоматизированный bridging может нарушать правила отдельных серверов. QuickBridge не содержит функций обхода античита, маскировки или античит-эвейжна. Используйте мод только там, где такие функции разрешены.

## Что есть в v0.1.0

- world-aware постановка блоков через реальные позиции игрока и соседние блоки;
- автоматический выбор строительных блоков из хотбара;
- Hold и Toggle режимы;
- аварийная остановка;
- HUD со статусом, техникой и количеством блоков;
- safety-stop при опасном падении, открытии GUI или отсутствии блоков;
- настраиваемый Sneak Assist;
- сохранение настроек в `config/quickbridge.properties`.

## Управление по умолчанию

| Клавиша | Действие |
| --- | --- |
| `B` | запуск/удержание QuickBridge |
| `N` | следующая техника |
| `K` | аварийный STOP |
| `O` | настройки |

Все клавиши можно переназначить через стандартное меню Minecraft **Controls**.

## Требования

- Minecraft Java **1.21.11**
- Forge **61.x** (проект собирается на 61.2.0)
- Java **21**

## Установка

1. Установить Forge для Minecraft 1.21.11.
2. Скачать JAR из GitHub Releases.
3. Поместить JAR в папку `.minecraft/mods`.
4. Запустить игру с профилем Forge.

## Архитектура

QuickBridge разделён на независимые слои:

- `BridgeTechnique` — каталог техник и параметры профилей;
- `BridgeEngine` — state machine движения/прыжков/размещения;
- `PlacementHelper` — поиск валидной позиции и постановка блока;
- `BridgeConfig` — пользовательские настройки;
- `QuickBridgeHudRenderer` — HUD;
- `QuickBridgeScreen` — меню конфигурации.

Такой подход позволяет добавлять новые техники без переписывания всего мода.
