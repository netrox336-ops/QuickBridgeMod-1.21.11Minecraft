# QuickBridge — Minecraft 1.21.11

**QuickBridge** — клиентский Forge-мод для автоматизированного бриджинга. Он управляет движением, камерой и постановкой блоков, ориентируясь на состояние мира и реальные подтверждения сервера, а не просто проигрывая фиксированный AHK-таймер.

> Автоматизированный bridging может быть запрещён правилами отдельных серверов. В QuickBridge нет обхода античита, маскировки или функций скрытия автоматизации. Используйте мод только там, где такие функции разрешены.

## Что нового в v0.5.0

В этой версии обучение стало оценивать не только отдельные placements, но и **целые циклы техники**. После завершения state-machine cycle QuickBridge смотрит, сколько блоков сервер подтвердил, были ли failures и recovery, после чего рассчитывает quality этого цикла.

Новые возможности:

- **Cycle Learning** — отдельная статистика успешности и качества целых bridge-циклов;
- **Network Condition** — профиль `STABLE / DELAYED / UNSTABLE`, рассчитанный по ACK блоков, reliability и частоте recovery;
- **Learning Checkpoints** — удачные learned-настройки периодически сохраняются как контрольная точка;
- **Auto Rollback** — если после изменения параметров несколько циклов подряд заметно ухудшаются, learned-поправки автоматически возвращаются к последнему хорошему checkpoint;
- **Training Mode** — можно тестировать технику и видеть статистику циклов без записи новых данных в постоянный профиль сервера;
- расширенный HUD со score последнего цикла, состоянием сети, training-статистикой и количеством rollback;
- экран обучения теперь показывает cycle success, quality EMA, лучший результат и checkpoint.

### Как работает обучение

Ручная калибровка по-прежнему остаётся основной. Auto Learning добавляет к ней только ограниченную learned-поправку.

QuickBridge отдельно хранит данные для каждой пары **сервер + техника**. Один сервер не меняет профиль другого.

В v0.5 обучение использует два уровня:

1. **Placement feedback** — подтверждён ли конкретный блок и сколько тиков занял ACK.
2. **Cycle feedback** — насколько успешно прошёл весь цикл техники с учётом failures и recovery.

Если сервер сейчас нестабилен, вес новых изменений автоматически уменьшается.

### Training Mode

Тренировочный режим нужен для проверки техники и ручной калибровки. Во время него:

- обычный bridging и recovery продолжают работать;
- HUD считает успешность и качество циклов;
- persistent Server Learning не изменяется;
- тренировочную статистику можно сбросить в любой момент.

Это удобно перед тем, как включать Auto Learning на постоянном профиле.

## Recovery

Recovery работает отдельной последовательностью:

`HOLD → REALIGN → RETRY → RESUME`

Если сервер вовремя не подтвердил блок, QuickBridge останавливает обычный цикл, удерживает игрока, доворачивает камеру к проблемной позиции, повторяет placement и только затем возвращается к bridging.

Для Telly, Speed Telly, Andromeda и Blink используются более осторожные recovery-параметры.

## Калибровка

Для каждой техники отдельно доступны:

- **Длина цикла**;
- **Упреждение блока**;
- **Скорость поворота**;
- **Cadence bias**.

Редактор показывает ручные, learned и итоговые effective-параметры. Ручную калибровку и обучение можно сбрасывать независимо.

## Управление по умолчанию

| Клавиша | Действие |
| --- | --- |
| `B` | запуск/удержание QuickBridge |
| `N` | следующая техника |
| `K` | аварийный STOP |
| `O` | настройки |

Все клавиши можно переназначить через стандартное меню Minecraft **Controls**.

## HUD

Диагностический HUD может показывать:

- текущую технику и фазу;
- количество блоков;
- confirmed / recovery / failed placements;
- edge distance;
- скорость игрока;
- adaptive cadence;
- текущий ACK;
- reliability;
- качество последнего bridge-cycle;
- Network Condition;
- накопленную cycle-statistics;
- confidence обучения;
- число автоматических rollback;
- отдельную статистику Training Mode.

## Требования

- Minecraft Java **1.21.11**
- Forge **61.x** — проект собирается на **61.2.0**
- Java **21**

## Установка

1. Установите Forge для Minecraft 1.21.11.
2. Скачайте JAR из GitHub Releases.
3. Поместите JAR в `.minecraft/mods`.
4. Запустите Minecraft с профилем Forge.

Более подробное описание профилей находится в `docs/TECHNIQUES.md`.
