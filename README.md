# QuickBridge — Minecraft 1.21.11

**QuickBridge** — клиентский Forge-мод для автоматизированного бриджинга. Мод управляет движением, камерой и постановкой блоков, ориентируясь на реальное состояние мира и подтверждения сервера, а не просто проигрывая фиксированный AHK-таймер.

> Автоматизированный bridging может быть запрещён правилами отдельных серверов. В QuickBridge нет обхода античита, маскировки или функций скрытия автоматизации. Используйте мод только там, где такие функции разрешены.

## Что нового в v0.4.0

Главное изменение — **Server Learning**. QuickBridge теперь может постепенно подстраивать выбранную технику под фактическое поведение конкретного сервера.

Мод отдельно запоминает для каждой техники и каждого сервера:

- сколько placement было подтверждено и отклонено;
- среднюю задержку появления поставленного блока;
- сколько установок удалось восстановить через recovery;
- накопленную уверенность профиля;
- небольшие learned-поправки к длине цикла, placement lead, скорости вращения и cadence.

Обучение не перезаписывает ручную калибровку. Ручные параметры остаются базой, а learned-поправка хранится отдельно в `config/quickbridge-learning.properties`. Профиль одного сервера не влияет на другой.

### Новый Recovery

Recovery теперь работает отдельной последовательностью:

`HOLD → REALIGN → RETRY → RESUME`

Если сервер вовремя не подтвердил блок, QuickBridge прекращает обычный цикл техники, удерживает игрока, при необходимости доворачивает камеру к проблемной позиции, повторяет placement и только после этого возвращается к bridging.

Для Telly, Speed Telly, Andromeda и Blink используются более длинные стадии realign/resume, чем для обычных техник.

### Статистика и HUD

В настройках появился экран **Статистика сервера**. Там можно посмотреть для выбранной техники:

- количество накопленных samples;
- общий процент успешных placements;
- средний ACK в тиках;
- confidence обучения;
- learned-поправки;
- итоговые effective-параметры;
- число recovery success и failures.

Learning HUD можно включить или выключить отдельно. Он показывает накопленную статистику прямо во время игры.

## Техники

В QuickBridge доступны 14 профилей:

- Ninja
- Diagonal Ninja
- Breezily
- Witchly
- God Bridge
- Jump God
- Telly
- Speed Telly
- Side Bridge
- Time Bridge
- Andromeda
- Blink Bridge
- Slope Bridging
- Moonwalk

Профили с пометкой `[EXP]` остаются экспериментальными и требуют практической калибровки под конкретную физику сервера и задержку соединения.

## Калибровка

Для каждой техники отдельно доступны:

- **Длина цикла**;
- **Упреждение блока**;
- **Скорость поворота**;
- **Cadence bias**.

В v0.4 редактор также показывает learned-correction текущего сервера и итоговые effective-параметры. Ручной профиль и обучение можно сбрасывать независимо.

## Управление по умолчанию

| Клавиша | Действие |
| --- | --- |
| `B` | запуск/удержание QuickBridge |
| `N` | следующая техника |
| `K` | аварийный STOP |
| `O` | настройки |

Все клавиши можно переназначить через стандартное меню Minecraft **Controls**.

## Safety / Recovery

В настройках доступны:

- Auto Select Blocks;
- Sneak Assist;
- Stop on Fall;
- Stop on GUI;
- Placement Recovery;
- число recovery attempts;
- confirmation window;
- Fail-stop;
- Restore View;
- Diagnostic HUD;
- Auto Learning;
- Learning HUD.

## HUD

Диагностический HUD может показывать:

- текущую технику и фазу;
- количество блоков;
- confirmed / recovery / failed placements;
- edge distance;
- скорость игрока;
- adaptive cadence;
- текущий ACK;
- reliability текущего запуска;
- накопленные samples и reliability профиля сервера;
- confidence обучения.

## Требования

- Minecraft Java **1.21.11**
- Forge **61.x** — проект собирается на **61.2.0**
- Java **21**

## Установка

1. Установите Forge для Minecraft 1.21.11.
2. Скачайте JAR из GitHub Releases.
3. Поместите JAR в `.minecraft/mods`.
4. Запустите Minecraft с профилем Forge.

Более подробное описание профилей находится в `docs/TECHNIQUES.md`.
