# Smart Placement Planner — QuickBridge v0.8.0

Smart Placement Planner отвечает только за выбор следующего target-блока. Он не заменяет Technique State Machine, Execution Guard, Recovery или Server Learning.

## Последовательность

1. State Machine решает, что placement сейчас разрешён.
2. Placement Planner строит кандидатов вдоль направления движения.
3. Кандидаты проверяются на доступный attachment и дистанцию.
4. Кандидаты сортируются по score.
5. Pending targets пропускаются.
6. Первый реально выполнимый кандидат отправляется в `PlacementHelper`.
7. После отправки блок всё равно считается успешным только после фактического появления в мире.

## Что влияет на score

- расстояние от ожидаемого placement lead;
- боковое отклонение;
- число соседних блоков, к которым можно прикрепить новый блок;
- дистанция от глаз игрока до точки взаимодействия;
- движение вперёд по линии текущего bridge-профиля.

## Path Probe

Path Probe не пытается предсказывать скрытое состояние сервера. Он использует только уже загруженный клиентский мир и смотрит ближайший участок по направлению движения.

Void впереди является нормальным состоянием для бриджинга. Path Guard реагирует только на блоки, которые реально перекрывают движение игрока на уровне ног или головы.
