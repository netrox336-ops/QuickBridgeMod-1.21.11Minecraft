# Smart Placement Planner — QuickBridge v0.9.0

Smart Placement Planner отвечает за выбор следующего target-блока. Он не заменяет Technique State Machine, Execution Guard, Recovery или Server Learning.

## Последовательность

1. State Machine решает, что placement сейчас разрешён.
2. Route Stability формирует скорректированный world-direction vector.
3. Placement Planner строит кандидатов вдоль этого направления.
4. Кандидаты проверяются на доступный attachment и дистанцию.
5. Для каждого кандидата считается score, включая route error при включённом Route Stability.
6. Кандидаты сортируются по score.
7. Pending targets пропускаются.
8. Первый реально выполнимый кандидат отправляется в `PlacementHelper`.
9. После отправки блок считается успешным только после фактического появления в мире.

## Что влияет на score

- расстояние от ожидаемого placement lead;
- локальное боковое отклонение от текущего movement-вектора;
- число соседних блоков, к которым можно прикрепить новый блок;
- дистанция от глаз игрока до точки взаимодействия;
- движение вперёд по линии текущего bridge-профиля;
- отклонение target от центральной Route Stability оси.

## Route penalty

Начиная с v0.9 planner получает route snapshot. Для каждого кандидата вычисляется `routeError` — абсолютное расстояние центра target-блока от центральной оси моста.

Если Route Stability включён, это расстояние превращается в дополнительный penalty. Его сила зависит от выбранного режима:

- `GENTLE` — слабый штраф;
- `NORMAL` — стандартный;
- `STRONG` — сильнее удерживает targets возле центра.

Route penalty не делает кандидата автоматически запрещённым. Если центральный target невозможно прикрепить, planner всё ещё может выбрать боковую альтернативу с более низким score.

## Path Probe

Path Probe не пытается предсказывать скрытое состояние сервера. Он использует только уже загруженный клиентский мир и смотрит ближайший участок по направлению уже скорректированного движения.

Void впереди является нормальным состоянием для бриджинга. Path Guard реагирует только на блоки, которые реально перекрывают движение игрока на уровне ног или головы.

## Диагностика

HUD v0.9 показывает:

- число scanned/viable candidates;
- rank выбранного кандидата;
- итоговый score;
- `lane` — route error выбранного target;
- planner misses;
- path gap/obstacle/support telemetry.
