# QuickBridge — профили техник

QuickBridge 0.1.0 использует единый Bridge Engine. Профиль техники задаёт стиль движения, частоту попыток постановки, ритм прыжков и дополнительные placement attempts.

| Профиль | Статус | Базовый стиль |
| --- | --- | --- |
| Ninja | stable | backward + edge sneak |
| Diagonal Ninja | stable | diagonal backward + edge sneak |
| Breezily | stable | backward + alternating strafe |
| Witchly | stable | backward + alternating strafe |
| God Bridge | stable | backward-right + jump cadence |
| Jump God | experimental | faster jump cadence |
| Telly | experimental | sprint-forward + jump + burst placement |
| Speed Telly | experimental | accelerated Telly cadence |
| Side Bridge | stable | side movement |
| Time Bridge | experimental | timed placement cadence |
| Andromeda | experimental | high-rate diagonal/jump profile |
| Blink Bridge | experimental | burst-oriented profile |
| Slope Bridging | stable | backward + frequent jump for incline |
| Moonwalk | experimental | alternating backward strafe |

`[EXP]` означает, что профиль требует дальнейшей калибровки под реальную игровую физику и серверные ограничения. Это не режим обхода античита.
