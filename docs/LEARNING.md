# QuickBridge — обучение профилей

Начиная с v0.4.0 QuickBridge может накапливать локальную статистику поведения каждой техники на конкретном сервере.

## Что сохраняется

Для каждой пары сервер + техника отдельно сохраняются:

- количество наблюдений;
- confirmed / failed placements;
- recovery success;
- средняя задержка подтверждения блока;
- learned-поправки к cycle, lead, rotation и cadence.

Файл: `config/quickbridge-learning.properties`.

## Как применяется обучение

Ручная калибровка всегда остаётся базой. Auto Learning создаёт отдельную небольшую коррекцию. Её влияние зависит от confidence: первые наблюдения почти не меняют профиль, а по мере накопления статистики влияние плавно увеличивается.

Если сервер начинает подтверждать блоки медленнее или появляются failures, профиль осторожно снижает cadence и растягивает цикл. При стабильных быстрых подтверждениях он может постепенно вернуть более быстрый темп.

## Сброс

Через экран «Статистика сервера» можно сбросить:

- обучение только выбранной техники;
- всё обучение текущего сервера.

Ручная калибровка при этом не удаляется.

Auto Learning можно выключить полностью — тогда learned-профиль остаётся сохранённым, но не влияет на выполнение техник.
