# QuickBridge 0.2.0 — Minecraft 1.21.11

QuickBridge 0.2.0 перерабатывает исполнение сложных техник и контроль постановки блоков.

### Главное
- новый Rotation Engine с плавным yaw/pitch и отдельными профилями техник;
- Telly, Speed Telly и Blink разделены на фазы разбега и placement-window;
- движение считается в мировых координатах и не меняет направление из-за разворота камеры;
- новый Edge Detector вместо проверки только дробной координаты игрока;
- установка блока считается успешной только после фактического изменения мира;
- неподтвержденные placements автоматически повторяются ограниченное число раз;
- Fail-stop прекращает последовательность после серии ошибок;
- Restore View возвращает исходное направление камеры после остановки;
- HUD показывает фазу движка, подтвержденные установки, recovery, failures и расстояние до края;
- Auto Select Blocks выбирает наиболее полный стак строительных блоков;
- исправлен Toggle: после safety-stop состояние клавиши больше не остается логически включенным.

### Калибровка техник
В v0.2.0 индивидуально настроены placement lead, rotation speed, pitch, edge threshold, cycle/placement phase и oscillation для всех 14 профилей. Экспериментальные профили по-прежнему отмечаются `[EXP]`, поскольку реальное поведение может зависеть от серверной физики, задержки и правил размещения блоков.

QuickBridge не содержит функций обхода античита, маскировки или античит-эвейжна.
