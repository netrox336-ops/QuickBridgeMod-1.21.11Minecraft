# QuickBridge v0.8.0

Версия 0.8.0 перерабатывает выбор placement target и добавляет прогноз ближайшего участка моста.

## Главное

- новый `PlacementPlanner` вместо фиксированного набора target-позиций;
- ранжирование продольных и боковых placement-кандидатов;
- оценка attachment-соседей, дистанции и соответствия линии движения;
- `PathProbe` с прогнозом участка примерно на 2.4 блока вперёд;
- `Path Guard` для остановки движения перед настоящим препятствием;
- ожидаемый void впереди не считается препятствием;
- отдельные переключатели Smart Placement и Path Guard;
- HUD показывает candidate count, chosen rank/score, planner misses, gap/obstacle distance, support ratio и gap length.

## Совместимость

- Minecraft Java 1.21.11
- Forge 61.x, сборка проекта — 61.2.0
- Java 21
- старые ручные настройки и Server Learning сохраняются

В моде нет функций обхода античита, маскировки или скрытия автоматизации.
