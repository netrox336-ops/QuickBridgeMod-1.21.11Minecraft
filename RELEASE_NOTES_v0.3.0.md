# QuickBridge 0.3.0 — Minecraft 1.21.11

QuickBridge 0.3.0 переводит сложные bridging-профили на адаптивные state machines и добавляет индивидуальную калибровку каждой техники.

### Главное
- Telly / Speed Telly / Blink / Andromeda теперь работают через фазы RUNUP → JUMP → TURN → BURST → RESET;
- Breezily / Witchly / Moonwalk получили отдельные strafe-фазы;
- Adaptive Cadence учитывает скорость игрока, процент подтвержденных placements и задержку появления блока в мире;
- при нестабильном server ACK техника автоматически замедляется;
- Recovery Hold кратко останавливает движение во время повторной установки;
- placement lead получает поправку от фактической скорости игрока;
- добавлен экран калибровки техники;
- для каждого профиля отдельно сохраняются cycle scale, lead offset, rotation scale и cadence bias;
- HUD показывает Speed, Cadence, ACK latency и Reliability.

Экспериментальные профили по-прежнему отмечены `[EXP]`: практическая стабильность зависит от физики и сетевых условий конкретного сервера.

QuickBridge не содержит функций обхода античита, скрытия автоматизации или маскировки поведения.
